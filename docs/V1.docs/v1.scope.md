# V1 Scope — CodeSphere

## Included Scope

### Single-User Workflow

- One authenticated user session at a time
- No multi-user interaction

### File-Based Problem Bank

- Problems stored in repository (not MongoDB)
- Canonical, immutable, version-controlled content

### MongoDB Usage

Used exclusively for:

- User accounts
- Submission history
- Progress tracking

### Deterministic Evaluation

- Predefined test cases
- No AI involvement
- No dynamic generation
- No external nondeterministic calls

### Strict Architectural Separation

- Domain contracts
- Repository layer
- Service layer
- Infrastructure layer
- File-based canonical content

---

## Explicitly Excluded

The following are strictly out of scope:

- Teams
- Sheets
- Realtime collaboration
- Leaderboards
- AI-generated problems
- AI hints
- Admin panel
- Dynamic problem creation
- Contest mode
- Rating system
- Analytics
- Distributed systems
- Microservices
- Background workers
- Horizontal scaling

If not explicitly included, it is excluded.
