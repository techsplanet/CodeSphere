# CodeSphere *( name can change later )* 

* *CodeSphere is a community based coding web application build with the idea of encourageing coding culture and develop coding community at college level.*
* *Students can create coding group with their friends, create team, or join other's team to socialize, and discus coding problems in with their friends.*
* *See the skill and potential of Teams and of individuals from their profile pages and weekly-monthly platform ranking board.*
* *Teams and Individuals can curate their own coding practice sheet which can help hundreds of other individuals to build problem solving skills with right start*.

#### Project Architecture :-

1. Nextjs powered frontend web app --- utilize the edge capability.
2. MongoDB --- for growing dataset needs.
3. External Compiler --- to be utilized in the edge environment.
4. Realtime Node Server --- future realtime functionality.
